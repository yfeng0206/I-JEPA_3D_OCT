feat: seed pretraining and make guide cache builds resumable

SEEDING
train_patch.py set no seed, so two runs differing in one config field also
differed in crop draws, mask draws and dropout. That is why the ep30
comparison could not honestly claim the arms differ ONLY in masking, and why
pretraining-seed variance was unmeasurable. meta.seed is now read and applied
to random/numpy/torch with a rank offset for DDP.

Verified: identical seed reproduces target and context masks exactly; a
different seed diverges. This is what makes replicated forks possible.

RESUMABLE CACHE BUILD
A 600k-slice build takes ~1 hour and had no resume, so any interruption
restarted from zero. Volumes are now skipped when an existing file opens,
carries this schema, has the expected shape, AND records the same adapter sha
-- a truncated or foreign file is rewritten rather than trusted. Progress and
cache_meta.json record how many were reused.

This mattered immediately: a build was killed at 1750/6000 by a
Select-Object -First in the invoking pipeline, and the retry reused 1800.
