fix(train): write a rolling -last checkpoint every epoch

The anatomy_v2 run crashed at the epoch 29->30 boundary and only
-best.pth.tar survived, at epoch 26. Three epochs (~9 h) were unrecoverable.

Two causes compounded:
* -best tracks validation loss, but validation uses a plain MaskCollator with
  42-cell rectangles while curriculum runs train on 16-cell anatomy blobs. Val
  loss therefore RISES as the ramp engages (0.1251 -> 0.1325 -> 0.1393) and
  -best stays pinned to the earliest post-warmup epoch. It is not a usable
  resume point for these runs.
* save_every=5 with ~3 h epochs left up to 15 h of exposure, and the crash
  landed one epoch before the first periodic save.

-last.pth.tar is now written every epoch via a temp file plus os.replace, so a
crash mid-write cannot corrupt the only good resume point. Cost is a 1.4 GB
write (~15 s) against ~3 h of compute.
